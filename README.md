# DecodeLabs Project 3: SQL Data Analysis

## Project Overview
This project focuses on using SQL queries to extract insights from a dataset. It demonstrates fundamental SQL skills for data analysis using SQLite and DB Browser for SQLite.

## Tools Used
- SQLite
- DB Browser for SQLite
- SQL

## Dataset Overview
- Total records: 1,200
- The dataset contains order and product-related information.
- Key fields include OrderID, Product, OrderStatus, UnitPrice, and TotalPrice.

## SQL Concepts Practiced
- `SELECT` — retrieve data
- `WHERE` — filter records
- `ORDER BY` — sort results
- `GROUP BY` — group data for analysis
- `COUNT()` — count records
- `SUM()` — calculate total sales
- `AVG()` — calculate average values

## Key Findings
- **Total records:** 1,200
- **Total sales:** 1,264,761.96
- **Average order value:** 1,053.97 per record
- **Highest order status count:** Cancelled, with 250 records
- **Highest total sales by product:** Chair, with 195,620.11
- **Highest average order value by product:** Laptop

This project provided practical experience in querying and analyzing structured data using SQL. The analysis covered filtering, sorting, grouping, and aggregate calculations to identify order patterns and product sales insights.
